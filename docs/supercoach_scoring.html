SuperCoach AFL Scoring Guide

SuperCoach AFL is a fantasy platform enjoyed by thousands of virtual coaches each year. However, this doesn’t mean the scores are easy to understand.

Base Values

There are over 50 unique actions a player can do on field that would earn them ranking points.

Zone multipliers

Actions inside D50 or F50 are worth 20% more than the MID zone.

State of game multiplier

All actions are weighted by the state of the game: a metric determined by the margin and how much time is remaining. The formula for the weights is calculated using this formula. You can read how I derived this in my SuperCoach Scaling article.

The “3300 points” rule

All matches are assigned 3300 SuperCoach points. Due to individual player scores being rounded, not every match finishes on exactly 3300, but is always very close.
